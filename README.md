# Стальной рубеж — Tank Game

Актуальная сборка main проверена 13.09.2026: браузерный запуск, 5-секундный стартовый отсчёт, рельеф карт, цветовой индикатор пробития, маска брони, 3×3 с ботами и LAN 1×1 через Radmin VPN.

Браузерная 3D-игра про танковые сражения на JavaScript и Three.js. Репозиторий содержит рабочую версию ремастера 2.0 и локальный режим 1×1 через Radmin VPN.

Репозиторий: https://github.com/Retmixer/Tank-Game

## Возможности

- ангар и 9 танков трёх наций;
- индивидуальные 3D-модели всех 9 танков: разные корпуса, башни, ходовая часть, орудия и внешнее оборудование;
- детали подвески, люки, решётки, перископы, буксировочные серьги и запасные траки; замкнутые коллизии корпуса, башни и гусениц, включая обломки;
- исследование и покупка техники за опыт и серебро;
- уровни модернизации и сохранение прогресса в `localStorage`;
- бой 3×3 с ботами на трёх увеличенных картах;
- разгон по массе и мощности двигателя, сопротивление на подъёмах, торможение перед задним ходом; общая модель движения для игрока, ботов и LAN;
- локальный бой 1×1 через лобби и Radmin VPN;
- пятисекундный отсчёт перед началом боя;
- прицеливание на `Shift` с увеличением по характеристикам танка;
- индикатор пробития: зелёный, оранжевый и красный;
- маска брони в ангаре;
- индивидуальная толщина 9 зон брони каждого танка; маска и пробитие используют общие значения в миллиметрах с учётом модернизации;
- процедурные PBR-материалы, тени, ambient occlusion, постобработка;
- дальнее окружение: горы, леса, города, дороги и скалы;
- эффекты выстрелов, попаданий, дыма, пыли и следов гусениц.

## Быстрый запуск

Нужен Node.js и браузер с WebGL.

```powershell
node server.cjs
```

Откройте `http://127.0.0.1:8765`. На Windows можно запустить `PLAY.cmd` двойным щелчком.

Для локальной игры оба игрока подключаются к одной сети Radmin VPN, открывают адрес хоста `http://26.x.x.x:8765`, выбирают режим «Локальная сеть 1×1», а затем используют код лобби.

## Управление

`W/S` — движение, `A/D` — поворот корпуса, мышь — башня и камера, `ЛКМ` или `Space` — огонь, `Shift` — прицел, `Tab` — команды, `Esc` — пауза.

## Структура проекта

- `index.html`, `style.css` — интерфейс;
- `src/data.js` — танки, карты, экономика и миграция сохранений;
- `src/game.js` — сцена, бой, AI, сетевая логика и управление;
- `src/remaster.js`, `src/remaster.css` — графический ремастер и HUD;
- `src/platform.js` — localStorage и интеграция Яндекс Игр;
- `server.cjs` — локальный HTTP-сервер и relay для LAN;
- `tests/` — автоматические проверки;
- `docs/BALANCE.md` — характеристики и экономика;
- `Yandex-Games.zip` — архив для загрузки в консоль Яндекс Игр.

## Работа с репозиторием

Все работают напрямую в общей ветке `main`:

```powershell
git pull origin main
git add .
git commit -m "Описание изменения"
git push origin main
```

Ветки, pull request и обязательные проверки не требуются. Тесты можно запускать по желанию, если нужно быстро проверить игру:

```powershell
node tests/economy.cjs
node tests/remaster.cjs
node tests/models.cjs
node tests/simulation.cjs
```

## Ограничения

Сетевая игра рассчитана на двух игроков в одной виртуальной локальной сети и не является интернет-матчмейкингом. Броня и пробитие имеют аркадную модель. Окружение процедурное и не заменяет полноценные авторские 3D-модели.
