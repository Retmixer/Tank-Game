# Перед публикацией

1. Загрузить `Yandex-Games.zip` в черновик игры, платформа ПК, язык русский.
2. Открыть черновик с debug-панелью: проверить готовность LoadingAPI, GameplayAPI при начале/конце боя и паузе.
3. Проверить Player API с доступным и недоступным облаком, повторный вход и приоритет нового сохранения.
4. Пройти несколько боёв на каждой сложности и карте; измерить FPS на целевых слабых ПК, проверить fullscreen и захват мыши в поддерживаемых браузерах.
5. Добавить оригинальную обложку, иконку, скриншоты и описание в карточку. В самой игре встроены оригинальные процедурные ресурсы; рекламных SDK, платежей и внешних ссылок нет.
6. Отправить на модерацию. Архив подготовлен технически, но прохождение модерации не проверено и не обещается.

Локально проверены: расчёты всех 45 состояний прокачки, награда первого боя, валидация повреждённых сохранений, игровая симуляция на 3 картах, стрельба/попадания ботов, пауза, результат, улучшение; запуск WebGL и GUI в браузере.
