# Архитектура «Стального рубежа»

Игра работает в браузере на JavaScript и Three.js/WebGL. `server.cjs` раздаёт файлы и поддерживает LAN-лобби 1 × 1. Модели построены из собственной геометрии; поверхности используют локальные CC0 PBR-текстуры Poly Haven. Звуки синтезируются в браузере.

## Основные модули

- `src/data.js` — 12 машин, характеристики, экономика, карты и функции физики.
- `src/game.js` — сцена, бой, управление, AI, HUD и звук. Состояния: ангар, бой, результат.
- `src/remaster.js` — модели, материалы, подвеска, растительность, освещение и пакетирование неподвижной геометрии.
- `src/platform.js` — локальное и облачное сохранение, события платформы.
- `server.cjs` — статические файлы и relay для локальных матчей.
- `assets/textures` — локальные diffuse, normal и roughness карты; `SOURCES.md` указывает происхождение и лицензию.
- `tools/build-web.cjs` — готовит `dist` для Android WebView. `npm run mobile:sync` обновляет Android-проект.

## Карты и столкновения

Все три карты используют одну высоту для визуальной сетки, опор объектов и движения. Большие здания и укрытия имеют явный прямоугольный след вместо границ, включающих декор. Статические препятствия индексируются по ячейкам 24 м, чтобы не проверять весь список каждый кадр. Спавны сглажены; `tests/map-layout.cjs` проверяет свободу, рельеф и маршрут к центру для каждой команды.

Танк сталкивается с ориентированным корпусом другого танка. Лобовое столкновение останавливает ход, касание боком сохраняет лишь небольшую долю скорости. Боты строят короткий объезд стоящих машин. Гусеницы и подвеска учитывают рельеф. Снаряды проверяются лучом вдоль пройденного за кадр сегмента.

## Визуал и сборки

Материалы грунта, песка, снега, дорог, камня, кирпича, дерева, стали, окрашенной брони и гусениц используют готовые текстуры из интернета, упакованные локально. Размер повторения UV на больших стенах и опорах зависит от физического размера объекта. На Windows `npm run build:web` создаёт веб-ресурсы, `npm run mobile:sync` копирует их в Android, Gradle собирает APK. Архив для Яндекс Игр содержит те же веб-ресурсы.

## Проверка

`npm test` проверяет экономику, модели, физику, маршруты на картах, столкновения и полноценную симуляцию матча в Node с подменённым GPU. Нужны отдельные визуальные и производительные прогоны на целевых телефонах и ПК, проверка LAN на двух устройствах и SDK Яндекс Игр в черновике. Эти проверки описаны в `RELEASE-CHECKLIST.md`.
