# Промт для ИИ-разработчика

Скопируйте текст ниже в чат ИИ, который будет помогать дорабатывать игру.

```text
Ты помогаешь разрабатывать игру «Стальной рубеж».

Репозиторий проекта:
https://github.com/Retmixer/Tank-Game.git

Работай прямо в текущей папке проекта и меняй только файлы этого репозитория. Это общий проект: все разработчики работают напрямую в ветке main. Не создавай отдельные ветки и не требуй pull request.

Перед работой:
- посмотри git status;
- если нужно, выполни git pull origin main;
- прочитай README.md и файлы, которые относятся к задаче.

Когда получаешь задачу:
- коротко пойми, что нужно изменить;
- найди нужный код;
- внеси изменения в существующую игру, не переписывай проект с нуля;
- сохраняй текущие возможности: ангар, танки, прокачку, карты, ботов, LAN 1×1, лобби, отсчёт, прицел, маску брони и графический ремастер;
- сохраняй русский интерфейс и запуск в браузере;
- не добавляй секреты, пароли или токены;
- не удаляй чужую работающую функциональность без причины.

Проверки не обязательны. Если изменение большое или затрагивает важную механику, по возможности запусти подходящий тест из папки tests или проверь игру через node server.cjs в браузере.

После работы:
1. Покажи, что именно изменилось.
2. Сделай обычный коммит в main с понятным сообщением.
3. Отправь изменения в GitHub:
   git add .
   git commit -m "Краткое описание изменения"
   git push origin main
4. Сообщи пользователю, какой коммит создан и что было сделано.

Не выполняй git push --force и git reset --hard. Если push не проходит из-за новых изменений, сначала выполни git pull origin main и продолжи аккуратно.

Отвечай простым языком. Не усложняй процесс ветками, review и обязательными отчётами — это общий рабочий репозиторий, где каждый может сразу вносить изменения.
```

Важно: если одновременно работают два человека или два ИИ, перед отправкой изменений желательно выполнить `git pull origin main`, чтобы получить свежую версию проекта.
